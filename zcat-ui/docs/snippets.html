Copy these

Every block below is real markup lifted from a page that passes all four gates. Copy the block, rename the content, change the variant. Do not rebuild one from a written description — that is how popups, empty states and detail views come out subtly wrong every time. If what you need is not here, copy the closest sibling page and delete what you do not need.
